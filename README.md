# ScanQR

An Android (Kotlin Multiplatform) application that uses the `qr-kit` library to generate and scan QR codes. This project demonstrates cross-platform QR functionality using JetBrains Compose Multiplatform and Android-specific integrations.

## Features

- Scan QR codes using the device camera
- Built using Kotlin Multiplatform and Jetpack Compose
- Modular structure for platform-specific and shared logic

## Tech Stack

- Kotlin Multiplatform
- Compose Multiplatform
- Android SDK
- QR-Kit library
- Gradle Kotlin DSL
